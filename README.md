# Hacktoberfest 2026 with Python User Group Singapore

A working space for the PUGS NLB LearnX preamble on Friday 25 September 2026 and the Hacktoberfest meetup on Friday 30 October 2026. We will learn how to propose small, useful open-source changes and create [Agent Skills](https://agentskills.io/specification). This repository is a workshop, not an official Hacktoberfest registration page or a guarantee that a practice PR counts toward a reward.

## Start here

- New contributor? Read [CONTRIBUTING.md](CONTRIBUTING.md), then choose one open issue marked `good first issue` (after a maintainer publishes the issues). Comment before starting so you do not duplicate work.
- Skill exercise: read [the example skill](skills/dataset-card-reviewer/SKILL.md), then follow [Add your own SKILL.md](EXERCISE.md). Your skill should do a small, real task. Please do not submit an untested template or a copy of the example.
- Site: [workshop landing page](https://pythonsingapore.github.io/hacktoberfest26/) after GitHub Pages is enabled. Until then, use this README.
- 25 September preamble: GitHub setup, PR flow, a tiny Python dataset-card checker, and a skill sketch.
- 30 October meetup: continue a reviewed task or demonstrate and test a skill. Confirm times, venue, online link and registration with PUGS before travelling; these details may change.

## Contribution loop

Read the issue and guide -> discuss scope -> fork -> make a branch -> change one thing -> check your work -> open a PR explaining it -> respond to review. A maintainer decides whether to merge. No filler PRs, automated floods or personal information in sample skills.
