Two sessions

25 September · preamble

GitHub setup, a browser-based contribution walkthrough, Python practice and your first skill sketch.

30 October · meetup

Continue a reviewed task or demo a tested skill. Check PUGS announcements for final time, venue, online link and registration.

Try the exercise

  1. Open the working repository and read its README and contribution guide.
  2. Start with the interactive dataset-card reviewer walkthrough; then read the add your own SKILL.md exercise and example skill.
  3. Ask a maintainer which small task is wanted; make a focused branch, test, then propose a PR for review.

The repository is a workshop. A practice PR is not a promise of an official Hacktoberfest milestone or reward. Do not submit filler PRs.
