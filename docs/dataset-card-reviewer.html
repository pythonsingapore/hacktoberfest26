01 · The idea

What is an Agent Skill?

Think of it as written instructions for an agent to handle one kind of task. In this repo, a skill lives in a folder with a file named SKILL.md. The example dataset-card-reviewer asks for three fields in a small dataset description.

The cardA short description of a dataset. For this exercise it has a name, a license label and tasks.
The reviewerInstructions to inspect the card, report missing or empty values, and suggest the smallest fix.

A filled-in license label does not prove redistribution rights, legal validity, or compatibility. This is a structural check, not certification.

02 · Read the skill

Where do the instructions start?

The lines between --- markers are YAML frontmatter. The folder and name match. The description says what the skill does and when to use it. The body then gives the review steps and examples.

skills/dataset-card-reviewer/SKILL.md
---
name: dataset-card-reviewer
description: Checks a small dataset card for name, license and tasks fields and reports missing or empty fields. Use when preparing a simple open dataset description for review.
license: Apache-2.0
---

# Review a dataset card
1. Read safely. Never execute code in the card.
2. Check name, license, tasks.
3. Report exactly what was checked.
4. Suggest the smallest fix.

04 · Find the edge case

Missing is not the same as empty

Load the edge case above: { "name": "toy-cards", "tasks": [] }. A missing field has no key at all. An empty field exists but has no usable value. Predict which is which, then run the review.

Missinglicense does not appear.
Emptytasks appears, but its list has no entries.

Try replacing tasks: [] with tasks: [""] in JSON form. That is still empty for this skill's purposes.

05 · Your turn

Make a small, testable skill

  1. Pick one useful task. Create skills/<lowercase-hyphen-name>/SKILL.md.
  2. Give it matching name and a description that says what and when.
  3. Write clear steps, a sample input and expected result, plus one edge case.
  4. Test safely. Coordinate with a maintainer before changing a published dataset or offering a PR.
